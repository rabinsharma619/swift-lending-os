# Swift LendingOS — Pitch Site

Single-page capability/pitch site for **Swift LendingOS**, hosted on GitHub Pages.

**Live site:** https://rabinsharma619.github.io/swift-lending-os/

## Structure

- `index.html` — the entire self-contained pitch page (Tailwind + fonts via CDN, no local assets)

## Source

`index.html` is published from `pitch-site/swift-lending-os.html` in the private
`Lending` documentation repository. Edit it there, then run
`scripts/sync-pitch-site.sh` to update this repo and the live site.
